# 我的知识库

个人知识库，用 Markdown 记录、用 Git 管理。

## 目录

| 分区 | 用途 |
|---|---|
| [00-Inbox 随手记](inbox.md) | 随手记、灵感、待整理的内容 |
| [01-学习](study/index.md) | 课程、书籍、考试等学习笔记 |
| [02-编程](programming.md) | 代码、工具、踩坑记录 |
| [03-工作](work.md) | 项目、会议、工作方法 |
| [99-模板](note-templates/index.md) | 可复用的笔记模板 |

## 使用约定

- 文件名：`主题-关键词.md`
- 新内容先放进 00-Inbox，整理后再移到对应目录
- 每篇笔记开头写明日期、标签、状态
- 改完用 GitHub Desktop 提交并推送

## 快速开始

1. 用 GitHub Desktop 克隆仓库到本地
2. 用 Obsidian / VS Code / Typora 打开
3. 新建笔记时从 [笔记模板](note-templates/note-template.md) 复制
4. Commit → Push
